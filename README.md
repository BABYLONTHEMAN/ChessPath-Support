# ChessPath Support

Official public support and privacy repository for **ChessPath — Opening Explorer BETA**.

This repository contains **support information only**. The ChessPath extension source code is kept separately in a private repository.

## Get help

- **Bug reports:** use GitHub Issues
- **Incorrect opening / ECO data:** use the Opening Data issue template
- **Friend Play problems:** use the Friend Play issue template
- **Feature requests:** use the Feature Request template
- **Privacy policy:** see [PRIVACY.md](./PRIVACY.md)

## Support

Open a support issue here:

https://github.com/BABYLONTHEMAN/ChessPath-Support/issues

ChessPath is currently in beta, so reports about opening recognition, theory branches, interface behavior, and online Friend Play are especially useful.
